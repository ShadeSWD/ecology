# ecology — Промышленная экология

Статический учебный сайт (чистые HTML/CSS/JS, без сборки): курс промышленной
экологии с упором на транспорт и судоходство — качество атмосферного воздуха,
выбросы автотранспорта, судовое загрязнение и требования МАРПОЛ.

**Прод:** https://shadeswd.duckdns.org/ecology/

## О сайте

Четыре главы теории и три расчётные страницы, где всё считается по шагам:
«формула = подстановка = результат». Нормативная часть собрана по первичным
текстам: приложения I–VI МАРПОЛ 73/78 в действующих редакциях (резолюции
MEPC.117(52), 118(52), 193(61), 115(51), 201(62), 277(70), 328(76)),
руководства по судовому природоохранному оборудованию (MEPC.107(49) —
сепараторы льяльных вод, MEPC.227(64) — установки обработки сточных вод,
MEPC.244(66) — инсинераторы, MEPC.340(77) — системы очистки выхлопных газов),
Конвенция о балластных водах со стандартами D-1 и D-2 (MEPC.297(72),
MEPC.298(72), Кодекс BWMS MEPC.300(72)), гигиенические нормативы качества
атмосферного воздуха. Утверждения, которые не удалось подтвердить
первоисточником, помечены на страницах явно.

## Содержание

- `site/` — сам сайт
  - `index.html` — обзор курса и навигация
  - `theory.html` — оглавление теоретического курса
  - `t-air.html` — атмосфера как среда: источники загрязнения, нормирование
    ПДК, классы опасности, рассеивание примесей
  - `t-water.html` — загрязнение вод: показатели качества, БПК и ХПК,
    нефтепродукты, очистка
  - `t-waste.html` — отходы: классы опасности, обращение, показатели
    материалоёмкости и комплексной оценки
  - `t-marine.html` — судно как источник загрязнения: нефтесодержащие и
    сточные воды, мусор, выбросы главных двигателей, балластные воды
  - `air.html` — расчёт качества воздуха: индекс загрязнения атмосферы,
    стандартный индекс, эффект суммации, вклад веществ в суммарный индекс
  - `transport.html` — расчёт выбросов автотранспорта: интенсивность и состав
    потока, удельные выбросы, масса выбросов, приведённая масса и ущерб
  - `marine.html` — судовое загрязнение: объёмы нефтесодержащих и сточных вод,
    подбор оборудования, выбросы оксидов серы и азота, проверка соответствия
    ограничениям, эффект перехода на низкосернистое топливо и скрубберы
  - `sources.html` — нормативы и учебники с пометками о подтверждении
  - `assets/` — `style.css`, `site.js` и расчётные модули `calc.js`, `air.js`,
    `transport.js`, `marine.js`
- `deploy/` — `docker-compose.yml` (nginx:alpine, порт 8076) и конфигурация nginx
- `tests/` — переносимый набор тестов целостности сайта (pytest)

## Запуск

```bash
cd deploy && docker compose up -d      # http://127.0.0.1:8076/
python3 -m pytest tests/ -v            # тесты целостности
```

Сайт входит в кластер учебных сайтов: общий подвал, словарь терминов и рендер
формул подключаются nginx-ом на уровне домена.
